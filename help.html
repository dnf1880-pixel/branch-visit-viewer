📋 拜访登记系统 · 使用说明

圆通速递 · 荆州/荆门/宜昌/恩施/潜江 | 42 个网点 | v3.0

基本操作

  1. 登录 — 输入姓名和工号，浏览器记住，下次自动登录
  2. 选网点 — 点击下拉框搜索城市或网点名，选中后联系人/电话/地址自动带出
  3. 填备注 — 输入拜访中发现的问题，系统自动匹配标签（12大类，不用手动选）
  4. 提 交 — 点「提交登记」保存

标签系统

备注中如果包含关键词，自动打标。举例：写了"客诉"→ 自动标「服务品质」；写了"延误"→ 自动标「时效管控」。标签始终自动运行，不需要任何开关。

AI 智能待办

备注框下面的 🤖 开关，打开后根据已匹配的标签，自动生成 1-6 条待办任务。不开也不影响标签。

网点联系人

选网点后联系人自动出来。如果电话或联系人变了，直接改 → 点「保存网点信息」→ 以后选这个网点就是新信息了。

导出 / 导入

顶部 📤 导出 Excel，📥 导入 Excel。导入会自动去重（同一天、同一人、同一网点只保留一条）。换电脑时：旧电脑导出 → 发文件 → 新电脑导入。

看板

顶部 📊 按钮打开看板页面，可查看拜访统计、各网点覆盖情况、待办任务管理。点状态标签可切换「跟进中 / 已完结」。
